# BUBU & DUDU: ADVENTURE RUN

A mobile-first browser adventure featuring two fluffy bears, six obstacle stages, local progress saves, synthesized sound effects, and touch controls.

## Play

https://sagar-somaiya.github.io/ledger-legends/bubu-dudu-adventure-run/

## Controls

- Touch: use the joystick, JUMP, and RUN FAST buttons.
- Keyboard: A/D or arrow keys to move, Space/Up to jump, Shift to run fast.

Progress is saved locally in the browser on the device you play on. This standalone edition does not require a login or game server.
