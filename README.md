# 🎮 Ledger Legends

### An Interactive Accounting Learning Game

**Ledger Legends** is a browser-based accounting game designed to make learning **debit, credit, journal entries, and transaction analysis** more interactive and engaging.

Instead of simply reading accounting rules, players learn by analysing business transactions and selecting the correct debit and credit accounts.

## 🚀 Play the Game

🎮 **[Play Ledger Legends Live](https://sagar-somaiya.github.io/ledger-legends/)**

## 📌 Project Overview

Ledger Legends turns fundamental accounting concepts into a simple game.

Players are presented with business transactions and must determine:

* Which account should be debited
* Which account should be credited
* The correct accounting treatment
* Their accuracy and performance

The game tracks the player's progress through **score, accuracy, level, and streak**.
